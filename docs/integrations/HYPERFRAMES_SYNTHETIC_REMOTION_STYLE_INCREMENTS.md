**Known limitations:** The independent renderer still captures one static PNG per scene and repeats it to make MP4; therefore it does not reproduce Remotion's frame-dependent text rise, glow pulses, scene-number drift, progress fill, last-scene fade or generated soundtrack. The static style change MUST NOT be treated as animation or sound parity, no matter how high the three-frame SSIM becomes. The queue permits only a 60-second leased render, and a later native frame-render path needs a safe bounded renderer and trusted lease-heartbeat model; do not lengthen, bypass or silently renew the lease within the browser.
